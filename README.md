# trug. by focsera

> Hyperlocal neighbourhood-commerce platform connecting residents with independent local shops for everyday essentials.

---

## Portals Included
- **Customer Storefront**: Browse neighbourhood shops, categories, product catalogues, vendor-grouped cart, instant checkout & daily subscriptions.
- **Vendor Dashboard** (`/vendor/dashboard`): Catalog management, inventory tracking, live orders workflow, delivery slots & analytics.
- **Admin Control Tower** (`/admin/dashboard`): Vendor KYC verification, resident directories, platform orders surveillance & catalogue taxonomy.

---

## Quick Start (Localhost)

```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Deploy to Vercel (1-Click)

1. Import this repository into [Vercel](https://vercel.com).
2. Set the **Root Directory** to `frontend`.
3. Click **Deploy** (no database or environment variables required).

*(Optional: Add `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in Vercel settings whenever you want to connect live Supabase).*
